Introduction

In the last meeting, RAN1 made progress on remaining issues corresponding to transport block (TB) to codeword (CW) mapping. Sufficient agreement obtained to clarify mapping of logical channel entity to physical channel. The agreement reflected to 38.214 already but that for 38.212 is yet to capture. In this contribution we discuss preferable approach to complete corresponding specification.

Captured text for TS38.214 indicates CW disabling scheme to use particular combination of IMCS and rvid. On the other hand, so far no text in TS38.212 represents TB to CW mapping. The mapping rule is same as the one in LTE using DCI format 2C, therefore it is straight forward to inherit specification text from corresponding description. Our proposed modification on TS38.212 is as following:

- Identifier for DCI formats – 1 bits

- Carrier indicator – 0 or 3 bits as defined in Subclause x.x of [5, TS 38.213].

- Bandwidth part indicator – 0, 1 or 2 bits as determined by the number of DL BWPs [FIG:c51159da2bd17ec8db54] configured by higher layers. The bitwidth for this field is determined as [FIG:dcaa22a776e7aec5b1a8] bits, where

- Frequency domain resource assignment – number of bits determined by the following, where [FIG:649951daa9a56a216e9f] is the size of the active DL bandwidth part:

- If both resource allocation type 0 and 1 are configured, the MSB bit is used to indicate resource allocation type 0 or resource allocation type 1, where the bit value of 0 indicates resource allocation type 0 and the bit value of 1 indicates resource allocation type 1.

- For resource allocation type 0, the [FIG:c0820893f611b79d68fb] LSBs provide the resource allocation as defined in Subclause 5.1.2.2.1 of [6, TS 38.214].

- For resource allocation type 1, the [FIG:0796558f78c4af0feede] LSBs provide the resource allocation as defined in Subclause 5.1.2.2.2 of [6, TS 38.214]

- PRB bundling size indicator – 0 bit if the higher layer parameter prb-BundlingType is not configured or is set to 'static', or 1 bit if the higher layer parameter prb-BundlingType is set to 'dynamic' according to Subclause 5.1.2.3 of [6, TS 38.214].

- ZP CSI-RS trigger – 0, 1, or 2 bits as defined in Subclause 5.1.4.2 of [6, TS 38.214]. The bitwidth for this field is determined as [FIG:013c4409d961ef475a79] bits, where [FIG:982939fe11e602c5a08f] is the number of ZP CSI-RS resource sets in the higher layer parameter zp-CSI-RS-Resource.

- Modulation and coding scheme – 5 bits as defined in Subclause 5.1.3.1 of [6, TS 38.214]

- Modulation and coding scheme – 5 bits as defined in Subclause 5.1.3.1 of [6, TS 38.214]
