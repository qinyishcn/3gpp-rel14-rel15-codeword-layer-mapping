Introduction

In previous meetings, there are issues raised on layer to port mapping and TB to codeword mapping. In this paper, we further discuss aspects related to these two issues.

TB to codeword mapping

The necessity of explicitly defining TB to codeword mapping should be viewed from the whole Tx structure. Currently, UE determines which layer each codeword maps to according to following table. From the table it could be seen that number of layers first determines number of codewords, and then determine the corresponding layer mapping. For the case “Number of codewords” equal to 1, it has already been captured that codeword 0 is used.

Observation 1: Table 7.3.1.3-1 in 38.211 has already captured the mapping between TB and codeword when there is only one codeword and one TB transmitted.

Proposal 1: It is not necessary to further specify the relationship between TB and codeword when there is only one codeword and one TB transmitted.

Layer to port mapping

Currently there is no explicit indication of layer to port mapping in the spec. In our understanding, the simplest way is to map each layer to each antenna port one to one in increasing order of layer index and increasing order of DMRS port index.

Proposal 2: For layer to port mapping, each layer is mapped to each antenna port in increasing order of layer index and increasing order of DMRS port index.

Conclusion

In this contribution, the following proposals are given related to layer mapping:

Observation 1: Table 7.3.1.3-1 in 38.211 has already captured the mapping between TB and codeword when there is only one codeword and one TB transmitted.

Proposal 1: It is not necessary to further specify the relationship between TB and codeword when there is only one codeword and one TB transmitted.

Proposal 2: For layer to port mapping, each layer is mapped to each antenna port in increasing order of layer index and increasing order of DMRS port index.
