Title: Remaining Issues on Codeword Mapping

Introduction

In previous meetings, there are issues raised on layer to port mapping and the following agreement is achieved. In this paper, we further discuss aspects related to these two issues.

Agreement

For NR Rel-15, DMRS port ordering is performed as follows for one-CW transmission (DL)

Simple ordering with increasing index (port number)

Layer to port mapping

Currently there is no explicit indication of layer to port mapping in the spec. In our understanding, the simplest way is to map each layer to each antenna port one to one in increasing order of layer index and increasing order of DMRS port index.

For two codeword case, it is argued that for multi-TRP scenarios, re-grouping DMRS ports according to which codeword the ports belong to could bring some benefits for codeword level AMC. But such benefits are marginal since the basic logic for NR R15 codeword to layer mapping is not designed to optimize such scenarios. There are cases like 2/4 split between two TRPs and the corresponding codeword mapping and DMRS regrouping could not be adapted per TRP.

Proposal 1: For two CW case, each layer is mapped to each antenna port in increasing order of layer index and increasing order of DMRS port index.
